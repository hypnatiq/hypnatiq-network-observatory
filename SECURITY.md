# Security and Responsible Review

## Repository boundary

This repository contains the public documentation website only. It must not contain the private Windows application source, service code, signing material, update keys, API credentials, test captures, personal traffic, or machine-specific configuration.

## Reporting

Describe a concern without posting exploit details, credentials, personal data, or captured network evidence in a public issue. Use a private contact method before disclosing a vulnerability that could affect an installed build.

## Product safety principles

- Observation is not proof of malicious intent.
- Reputation and antivirus results are supporting evidence, not verdicts.
- Optional online lookups require clear disclosure of what leaves the device.
- Firewall or response changes require authority, preview, rollback, and verification.
- Product health must report each component separately instead of presenting one broad healthy state.

# Selected Interface Screenshots

These seven screenshots were selected from the HypNO 0.80 development build because they explain the product workflow without exposing local application paths, installed-software inventory, network addresses, firewall rule scopes, credentials, or captured personal traffic.

## Included

- `hypno-first-visit-tip-080.png`: first-visit explanation of firewall views
- `hypno-inspection-recovery-080.png`: recovery-aware investigation stages
- `hypno-intelligence-providers-080.png`: optional information-source catalog without a key or result
- `hypno-investigations-080.png`: empty saved-investigations state
- `hypno-settings-080.png`: privacy and protection settings routes
- `hypno-threat-knowledge-080.png`: local threat-knowledge boundary
- `hypno-tools-080.png`: grouped investigation and response tools

## Excluded

Other development screenshots showed machine-specific paths, local software, public or private network addresses, firewall rules, or device-state evidence. They remain private and must not be added to the public repository without a new sanitized capture and review.

## Claim boundary

The screenshots show interface design and a controlled development state. They do not prove that every function is installed, active, release-ready, or validated on another system.

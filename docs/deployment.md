# Repository and Website Relationship

## Current relationship

This public GitHub repository is documentation-first. It intentionally excludes the full Netlify source and machine-specific screenshots. Updating this repository does not deploy or replace the live site.

## GitHub

The public repository is `hypnatiq/hypnatiq-network-observatory`. Keep any GitHub website link pointed to `https://hyp-no.netlify.app/`. Do not enable GitHub Pages unless a separate, sanitized static package is prepared and reviewed.

## Future Netlify change

Use the authoritative private website source for a separately approved Netlify release. Before deployment, repeat the screenshot, secret, link, responsive-layout, form, and security-header checks. Do not deploy the private review copy stored in this portfolio workspace.

## Post-deployment validation

- Confirm every repository link and selected screenshot opens.
- Confirm no local path, address, credential, token, or private capture is present.
- Confirm the repository website field points to the live Netlify site.
- For a separate Netlify deployment, test canonical URLs, responsive layouts, theme, navigation, screenshot viewer, focus order, form behavior, and response headers.
